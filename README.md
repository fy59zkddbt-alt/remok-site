# REMOK V4

Статический HTML/CSS/JavaScript. Четыре кейса и калькуляторы сохранены. Контакты: телефон +7 905 955-50-06, Telegram и MAX.

Формы REMOK подключены через DOM-мост к штатной форме Tilda на той же странице. Без неё (локально или на GitHub Pages) отправки нет. Мост не использует собственный backend или прямые запросы.

[Инструкция, ограничения обязательного Email/маски Phone и проверка приёмщиков](tilda-export/README.md).

Техническая форма Tilda остаётся видимой. Реальную доставку из обеих форм требуется подтвердить в CRM, Telegram и Email. Перед коммерческим запуском нужны утверждённые юридические документы.
