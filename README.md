# REMOK — публикационная версия V4

Сайт находится в корне репозитория: index.html, styles.css, script.js. Четыре страницы объектов — в cases/, используемые изображения и видео — в assets/. Зависимостей и сборки нет; .nojekyll отключает обработку Jekyll.

Исходная V4 сохранена отдельно. В этой копии изменены только относительные пути к медиа и документация по размещению. V1–V3 и архив images2 не включены.

Для GitHub Pages выберите публикацию из ветки main, папка / (root). После включения Pages используйте фактический URL, показанный GitHub; отправка файлов в репозиторий сама по себе не означает включение Pages.

[Интеграция с Tilda](tilda-export/README.md).

Формы пока не отправляют данные. Перед коммерческим запуском нужны интеграция заявок, юридические документы вместо ссылок-заглушек, фотография директора и согласование основного домена. Текущие калькуляторы, кейсы, отзывы и контакты сохранены.
