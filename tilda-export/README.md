# REMOK → штатная форма Tilda

Две пользовательские формы REMOK (калькулятор и финальный CTA) используют единый мост submitLead(formData, sourceForm) в script.js, отмеченный TILDA FORM INTEGRATION POINT. HTML/CSS, кейсы и формулы не менялись. t123.html остаётся прежним: нового copy/paste для этого патча не требуется, нужно загрузить актуальный script.js с GitHub Pages.

## Поиск и заполнение

Мост ищет единственный textarea[name="calculator_result"] вне .prototype-form и его родительскую форму .t-form.js-form-proccess. Имя определяется среди текстовых input по autocomplete="name" либо data-tilda-rule="name"; телефон — по type="tel"/autocomplete="tel". При неоднозначности отправки нет. На опубликованной странице обнаружены Name, Phone и calculator_result; их имена в мосте не зашиты.

В поля имени/телефона передаются значения REMOK; в textarea — читаемая сводка: источник, имя, телефон, фактический расчёт, URL и только непустые UTM. Форматирование использует подготовленные hidden JSON-поля, без повторного вычисления. Финальная форма без расчёта указывает «Расчёт: не выполнялся».

Для изменённых значений вызываются bubbling input/change. После проверки обязательных полей нажимается штатная submit-кнопка Tilda. Собственных fetch/XHR/POST, endpoint и секретов нет. Защитный submit-listener отменяет только обычную HTML-навигацию, не останавливая обработчики Tilda.

## Состояния

Обе кнопки REMOK блокируются общим activeTildaSubmission, чтобы две формы не перезаписывали один технический канал. При ожидании показано «Отправляем…». POC продолжает работать вне отправки; во время отправки снимок заявки защищён от новых расчётов.

Успех подтверждается только событием tildaform:aftersuccess на выбранной форме, документированным здесь: https://help.tilda.cc/tips/javascript . Это подтверждение штатного обработчика Tilda, а не доказательство доставки во все приёмщики.

Ошибки отслеживаются по появлению штатных DOM-сообщений .js-errorbox-all / .t-input-error. После подтверждённого успеха или ошибки кнопки разблокируются. Через 45 секунд без подтверждения показывается нейтральное сообщение; блокировка сохраняется, поскольку заявка ещё может быть доставлена. Позднее событие успеха или ошибка завершают ожидание. Нет автоматических повторов.

## Фактические ограничения опубликованной формы

На странице https://remok.net/page248741309.html обнаружен обязательный Email (data-tilda-req="1"), которого нет в REMOK. Он не заполняется фиктивным значением и не отключается кодом. Для последнего теста владелец должен заполнить его в видимой форме Tilda либо снять обязательность в редакторе и перепубликовать страницу.

У Phone обнаружена телефонная маска и placeholder +1(000)000-0000. Нужно проверить её пригодность для +7. Если input/change изменили цифры переданного номера, мост остановит отправку, не отправляя искажённый телефон.

Штатные согласия и обязательные поля остаются действующими. Техническая форма остаётся видимой. На локальной/GitHub-странице без формы Tilda отправка не выполняется; показывается ошибка с альтернативными контактами.

## Проверка приёмщиков

По данным владельца активированы Tilda CRM «Ремок актуальный», Telegram и Email info@remok.net. Предыдущий POC подтверждён владельцем для Telegram/Email. Новый автоматический мост локально проверен с имитацией штатного submit, success/error, но реальная доставка из двух форм ещё требует проверки.

После загрузки нового JS:
1. Убедиться, что обязательный Email и маска Phone настроены корректно.
2. Отправить одну тестовую заявку из калькулятора, затем одну из финального CTA без расчёта.
3. Проверить имя, телефон, источник, расчёт, URL и UTM в каждой заявке.
4. Подтвердить каждую заявку одновременно в Tilda Leads/CRM, Telegram и info@remok.net.
5. Только после этого отдельно решать вопрос о скрытии технической формы.

Нажатие кнопки и сообщение success сами по себе не заменяют проверку трёх приёмщиков. Не добавлять недокументированные API или внутренние endpoint.

## Debug

В DevTools можно установить window.REMOK_DEBUG_LEADS = true. Выводятся только этапы вида «Tilda bridge: form found / submit triggered». Имя, телефон и текст заявки не логируются, в том числе локально. Диагностические предупреждения о недостающих полях не содержат значений.

Экспорт использует абсолютные HTTPS URL https://fy59zkddbt-alt.github.io/remok-site/. В Tilda остаётся один T123, без iframe. Не подключать script.js дважды. Текущие ссылки-заглушки юридических документов требуют согласованных реальных документов перед коммерческим запуском.
